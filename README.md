# Sclero-Wars

Sclero-Wars is a browser-based educational simulation for neurologists. It contains randomly generated synthetic MS patients, a 17-entry DMT arsenal, four six-month reviews, animated treatment battles, uncertain clinical draws, and economic/follow-up events.

## Upload to GitHub

Upload the **contents of this folder** to the root of a new GitHub repository. The repository root should contain `index.html`, the JavaScript and CSS files, `vercel.json`, and the `assets` folder.

## Deploy on Vercel

In Vercel, choose **New Project**, import the GitHub repository, and deploy it. This is a static browser game, so no build command or environment variables are required.

## Educational disclaimer

Patients, cost credits, economic probabilities, and scoring weights are synthetic teaching assumptions. The game is not a validated individual-patient prediction tool or a prescribing recommendation. Local approval, the full product label, individual assessment, and shared clinical decisions remain essential.
